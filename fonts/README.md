# Fonts

The two font files are not in git (39 MB). They are in the release zip, and `install.ps1`
installs them for the current user.

To build from source, download them and put them in this folder:

| File | Source | License |
|---|---|---|
| `NotoSerifCJKjp-Black.otf` | [notofonts/noto-cjk](https://github.com/notofonts/noto-cjk/tree/main/Serif/OTF/Japanese) | SIL OFL 1.1, `OFL-noto-cjk.txt` |
| `ShipporiMinchoB1-ExtraBold.ttf` | [fontdasu/ShipporiMincho](https://github.com/fontdasu/ShipporiMincho) / Google Fonts | SIL OFL 1.1, `OFL-shippori.txt` |

Yu Gothic Bold and Bahnschrift come with Windows 10 and 11.
